---

## 1. Konteks & Latar Belakang
Happy Bouquet membutuhkan sistem SEO modern dan dinamis yang dapat dikelola sepenuhnya dari Panel Admin tanpa harus mengubah kode sumber atau melakukan build ulang storefront:
1. **Meta & Social Share Statis**: Sebelumnya judul dan meta description diatur statis di file template Vue (`pages/index.vue`, `pages/products/index.vue`), sedangkan halaman detail produk (`/products/[slug]`) belum memiliki Open Graph image dan meta harga produk.
2. **Ketiadaan Structured Data (JSON-LD)**: Mesin pencari seperti Google belum dapat menampilkan Rich Results (rating bintang, harga mata uang IDR, status InStock, dan breadcrumb hierarkis).
3. **Peta Situs & AI Crawler**:
   * Belum ada `sitemap.xml` dinamis yang menyajikan daftar URL produk dan halaman statis secara real-time.
   * `robots.txt` hanya 2 baris statis tanpa arahan sitemap dan tanpa proteksi rute transaksi.
   * Belum ada `llms.txt` / `llms-full.txt` (standar llmstxt.org) untuk AI-driven search engines (ChatGPT Search, Perplexity, Claude, Gemini, Google AI Overviews).

## 3. Rincian Implementasi

### A. Backend API (`api-happyBouquet`)
1. Perluas `ALLOWED_KEYS` di `src/services/settingService.js`:
   * `seo_meta_title`
   * `seo_meta_description`
   * `seo_meta_keywords`
   * `seo_canonical_url`
   * `seo_og_image`
   * `seo_google_verification`
   * `seo_bing_verification`
   * `seo_robots_directive`
   * `seo_llms_summary`
2. Perbarui skema Zod di `src/controllers/settingController.js` agar menerima field-field tersebut secara opsional dengan batasan teks aman.

### B. Frontend Nitro Server Routes (`happybouquet`)
1. **`server/routes/robots.txt.ts`**:
   * Menghasilkan file robots dinamis dengan deklarasi `Sitemap: https://happybouquet.web.id/sitemap.xml`.
   * Melarang bot pada rute checkout, account, dan api.
   * Mendefinisikan izin crawler bot AI (GPTBot, PerplexityBot, ClaudeBot, Google-Extended) untuk `/` dan `/llms.txt`.
   * Menghapus file statis `public/robots.txt` agar rute Nitro aktif.
2. **`server/routes/sitemap.xml.ts`**:
   * Melakukan fetch produk aktif dari `${apiUrl}/products?active=true`.
   * Menghasilkan struktur XML standar dengan `<urlset>`, `<loc>`, `<lastmod>`, `<changefreq>`, dan `<priority>`.
   * Mengatur header `Content-Type: application/xml`.
3. **`server/routes/llms.txt.ts` & `llms-full.txt.ts`**:
   * Format markdown standar untuk AI Agent dan LLM Search Engines.
   * Memuat ringkasan toko, keunggulan bunga segar Grade A+, layanan same-day, katalog terpopuler, dan FAQ.

### C. Frontend Dynamic SEO & Schema.org Composable (`happybouquet`)
1. **`composables/useStoreSettings.ts`**:
   * Perluas antarmuka `StoreSettings` dan fallback nilai default SEO yang elegan.
2. **`composables/useSeo.ts`**:
   * Helper `useDynamicSeo()`: Mengatur judul halaman, meta description, canonical URL, OG tags, Twitter tags dari database settings dengan opsi override per halaman.
   * Helper `useSchemaOrg()`:
     * `schemaOrganization()`: LocalBusiness / Florist.
     * `schemaProduct(product)`: Detail produk dengan harga, mata uang IDR, ketersediaan stok, brand, rating.
     * `schemaBreadcrumbs(items)`: Hierarki navigasi URL.
     * `schemaFaq(faqs)`: Accordion pertanyaan yang tampil langsung di Google Search.
3. **Integrasi Halaman**:
   * `app.vue`: Verifikasi Google & Bing site verification meta tags.
   * `pages/index.vue`: Dynamic meta dari database + Schema Organization & FAQ.
   * `pages/products/index.vue`: Dynamic meta katalog + Schema Breadcrumb.
   * `pages/products/[slug].vue`: Dynamic meta produk + OG image + Schema Product & Breadcrumb.

### D. Panel Admin (`PanelHappyBouquet`)
1. **`src/composables/useSetting.ts`**:
   * Sinkronisasi interface `StoreSettings` dengan field-field SEO.
2. **`src/views/settings/StoreSettingView.vue`**:
   * Form input tab/section "Optimasi SEO & AI Search":
     * Meta Title & Meta Description dengan counter rekomendasi 150-160 char.
     * Kata Kunci / Keywords.
     * URL Gambar Social Share (OG Image) dengan pratinjau thumbnail.
     * URL Kanonikal Dasar.
     * Kode Verifikasi Google Search Console & Bing Webmaster.
   * **Live SERP & Social Preview**: Pratinjau langsung Google Search Card (Desktop & Mobile) dan bubble chat WhatsApp.
